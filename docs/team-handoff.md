## 接手任务

1. 使用团队 README 在每位组员电脑独立启动，使用各自本地数据库和测试账号。
2. 执行 npm test，补充 PC/手机视觉、键盘、录入、筛选和生命周期操作验收。
3. 审计账号登录、邀请码、会话和后端跨账号权限；本地离线模式不代表云端认证通过。
4. 核实数据库迁移、上传文件、备份恢复，禁止使用个人真实数据库测试。
5. 云端部署先提交方案再实施；检查认证、隔离、持久化、密钥、任务调度和大陆可访问性。
6. 快速记录的文字输入已接入 AI 识别（五个模块），但真实模型仍需实机验收；照片/语音识别默认关闭（`AI_MEDIA=1` 才开启），后台通知等未验收能力不能提前标记完成。
